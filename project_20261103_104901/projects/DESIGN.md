# 红楼梦·MBTI 人格测试（新中式国风）

## 类型
移动端互动测试网页（小红书虚拟商品）· 新中式国风

## 设计关键词
朱砂红、石青蓝、月白底色、淡墨海棠、潇湘竹影、毛笔书法标题、Q版国风人物、温婉雅致

## 色彩
- 主色（朱砂红）：#C0392B —— 按钮、强调、话题水印，取自朱砂印泥
- 石青蓝：#3E6B73 —— 说明文字、次要强调，取自国画石青颜料
- 背景（月白）：#FAF5EE —— 暖调月白，纸感温和
- 卡片表面：surface 色阶 #FFFDF9 → #F3E9DD（输入框/卡片）
- 主文字：#4A3226（深墨棕）；次文字：#8A7463（灰褐）
- 错误/提醒：#D65A4A

## 字体
- 标题：Ma Shan Zheng（马善政毛笔书法体），仅限标题/印章/品牌字
- 正文：Noto Sans SC（思源黑体圆润观感），行高舒适 1.6

## 布局与组件
- 375–430px 移动端竖屏优先，整屏呼吸感，卡片大圆角 + 软阴影
- 组件：五格验证码输入、Q版人物插画、人格标签 chips、进度条、分享海报（3:4）
- 页面流：验证码解锁 → 国风引导 → 答题 → 3秒加载 → 结果/海报

## 动效
页面切换淡入淡出 + 轻微上浮；按钮朱砂色波纹反馈；progress 平滑过渡

## 禁忌
禁止深色科技背景、强霓虹、过度商业化弹窗、非国风硬风格、emoji 当图标（用 Lucide + 国风插画）
